OTC類似薬 負担シミュレーター

薬剤費の4分の1が「特別の料金」として窓口負担に加わります。患者さんの窓口負担の増額と、先発・後発の違いを試算できます。使い方は、右端のタブにあります。

① 患者さんの条件

窓口負担割合

調剤技術料などは増額に影響しないため、入力は不要です。対象外になるケースは想定していません。対象成分の薬は、すべて特別の料金の対象として計算します(対象外のケースはページ下部にまとめています)。

② 処方薬

厚労省の対象医薬品リスト(1,042品目)から、薬を検索して選べます。選ぶと薬価が入ります。数量は処方内容に合わせて入力してください。内服は 薬価 × 1日量 × 日数、外用・点眼などは 薬価 × 処方総量で薬剤費を計算します。点眼液や外用薬の薬価は、1mLや1gあたりが多いので、総量は mL や g で入力します(5mLの点眼液1本なら 5)。

計算ルールの設定

端数処理と会計方法は公表資料で確認できていません。実際の運用が決まったらここを合わせてください。

窓口の支払いの計算式

入力した値を当てはめた計算です。調剤技術料などは含めず、薬剤費の分だけで計算しています。

負担割合ごとの比較

負担割合現行新制度増額

特別の料金は負担割合に関係なく一定です。負担割合が低いほど、増える割合は大きくなります。

このアプリでできること

  • OTC類似薬の特別の料金(薬剤費の4分の1)で、患者さんの窓口負担が、いくら増えるかを試算します。
  • 先発医薬品と後発医薬品で、窓口負担がどれくらい違うかを比べます。
  • 試算結果を、医療機関に提出するシートとして印刷します。

入力した内容は、この画面の中だけで処理されます。患者さんの個人情報は、入力も保存もしません。

患者さんの窓口負担を試算する

  1. 「患者さんの窓口負担」タブで、窓口負担割合(1割・2割・3割)を選びます。
  2. 「対象医薬品リストから探す」に、薬の名前を入れます。品名、成分名、メーカーで探せます。候補から選ぶと、薬の名前と薬価が入ります。
  3. 数量を入力します。内服薬は、1日量と日数です。外用薬や点眼液は、処方総量です。点眼液と外用薬の薬価は、1mLや1gあたりなので、5mLの点眼液1本なら5と入力します。
  4. 薬が複数あるときは、「＋ 内服薬などを追加」または「＋ 外用薬を追加」で、行を増やします。対象成分ではない薬を入れるときは、区分を「対象成分ではない薬」にします。
  5. 右側の「窓口負担の増額」で、増える金額を確認します。「窓口の支払いの計算式」で、計算の中身を確認できます。

先発と後発を比べる

  1. 「先発・後発の比較」タブを開きます。
  2. 先発医薬品と後発医薬品を、それぞれ検索して選びます。薬価と、OTC類似薬の対象かどうかが入ります。
  3. 数量を入力します。点眼液は、mLで入力します。
  4. 結果の上部に、先発を選んだ場合に窓口負担が増える金額が出ます。内訳の表で、保険の自己負担と特別の料金の違いが分かります。

OTC類似薬に該当する先発医薬品は、選定療養の特別の料金を加算しない整理にしています(厚労省の資料による)。両方を加算した場合の参考値は、「計算ルールの設定」で切り替えられます。

医療機関への提出用に印刷する

  1. 先に、「患者さんの窓口負担」と「先発・後発の比較」タブに入力します。
  2. 「提出用シート」タブを開き、医療機関名、薬局名、担当者名、作成日を入れます。
  3. 載せる内容を、チェックで選びます。
  4. ブラウザの印刷機能(Ctrl+P、Macは ⌘P)で印刷します。印刷時は、シートだけが出力されます。

入力内容を変えたときは、「提出用シート」タブを開き直してください。

見るときのポイント

  • 金額は、薬剤費の分だけで計算した概算です。調剤技術料などは含みません。実際の会計とは、数円ずれることがあります。
  • 対象外になるケース(こども、がん、指定難病など)は、反映していません。ページ下部に、まとめています。
  • 端数処理と消費税の扱いは、「計算ルールの設定」で変えられます。実際の運用が決まったら、合わせてください。
  • 薬価は、厚労省の対象医薬品リストの値です。薬価改定などで変わった場合は、数値を書き換えてください。

① 比較する薬と条件

薬価は、添付の対象医薬品リストの値です。初期表示は、アレジオンLX点眼液0.1%と、エピナスチン塩酸塩LX点眼液0.1%「SEC」(ともに5mL)です。点眼液の薬価は1mLあたりなので、数量は mL で入力します。

窓口負担割合

OTC類似薬の対象は、厚労省の対象医薬品リストの品目で決まります。点眼液が対象かどうかは、リストで確認してください。

計算ルールの設定

選定療養の特別の料金は、先発医薬品の薬価と後発医薬品の最高価格との差の2分の1です(2026年6月1日施行)。後発の最高価格は、選定療養の対象になる先発医薬品ごとに決まっています。

先発医薬品の計算式

この試算の前提

  • 厚労省の2026年8月27日付の資料に、OTC類似薬の一部保険外療養に該当する場合は、長期収載品の選定療養の特別の料金は求めないとあります。そのため、既定では、OTC類似薬に該当する先発医薬品に、選定療養の特別の料金は加算しません。
  • OTC類似薬に該当しない先発医薬品は、選定療養の特別の料金だけがかかります。
  • OTC類似薬の特別の料金は、その薬の薬剤費の4分の1です。後発医薬品も、対象品目であれば同じ割合でかかります。
  • 2027年3月以降の、選定療養の特別の料金の計算方法の変更は反映していません。通知が出たら確認が必要です。
  • 選定療養の対象外(医療上の必要がある場合など)は想定していません。点数換算の端数処理で、数十円ずれることがあります。

提出用シートの設定

「患者さんの窓口負担」と「先発・後発の比較」タブの入力内容が、そのままシートに載ります。内容を変えたら、このタブを開き直してください。

印刷は、ブラウザの印刷機能(Ctrl+P、Macは ⌘P)を使ってください。印刷時は、このシートだけが出力されます。環境によっては、ブラウザの印刷が使えない場合があります。

特別の料金の対象外になるケース

このシミュレーターには反映していません。実際には、次の8ケースで対象外になります(2026年9月30日の厚労省公表を報じた日本医事新報社の記事による)。

  • こども(18歳に達する日以後の最初の3月31日までの間にある者)
  • がん治療、またはがん治療に関連して生じた状態に使用する場合
  • 指定難病、小児慢性特定疾病(18歳から20歳までの者に限る)、またはこれらに関連して生じた状態に使用する場合
  • 国の公費負担医療で使用する場合
  • 侵襲を伴う検査、処置、手術に伴って使用する場合(検査等の後14日以内の使用に限る)
  • 医師が、年間を通じた症状の持続と治療の継続性を確認し、長期の使用が医療上必要と認める場合
  • 類似のOTC医薬品で承認されている効能・効果では対応できない状態に使用する場合
  • 妊婦、妊娠している可能性がある人、授乳婦が、特定の対象医薬品を使用する場合(指定薬のリストは厚労省のページを参照)

在宅時医学総合管理料など、薬剤料が包括される算定で院内処方する場合も対象外とされています。対象・対象外の別は、新しい処方箋様式の「一部保険外療養」欄に薬ごとに記載されます。

前提と注意点

  • 特別の料金は、OTC類似薬の薬剤費の4分の1です。残り4分の3に通常の負担割合がかかります。例:薬剤費1,000円・3割負担なら、保険の自己負担225円+特別料金250円=475円(端数処理前)。消費税を加えると約500円です。
  • 窓口負担は、薬剤費の分だけを1円未満四捨五入で計算しています。実際の会計は、調剤技術料などと合わせて10円未満を四捨五入するため、増額が数円ずれることがあります。
  • 検索で入る薬価は、厚労省の対象医薬品リスト(1,042品目)の値です。薬価改定などで変わった場合は、数値を書き換えてください。
  • 薬剤費は円で概算しています。薬価の点数換算や、剤ごとの端数処理は反映していません。
  • 高額療養費、乳幼児医療などの助成、自治体の独自制度による影響は含めていません。
  • このシミュレーターは、対象成分の薬すべてに特別の料金がかかる前提で計算しています。対象外のケースは下にまとめています。
  • 対象成分の一覧、妊婦等の指定薬、対象外の詳細は、厚生労働省「OTC類似薬の保険給付の在り方の見直しについて」で確認してください。
